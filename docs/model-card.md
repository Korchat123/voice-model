# Model card: no released model

> Status: **UNTRAINED — UNAPPROVED — UNRELEASED**

This repository does not currently contain or release a trained voice model.
The deterministic training fixture is infrastructure test data, not speech and
not a usable TTS model. No model weights are included in source/runtime release
archives.

## Approval state

- Voice-owner consent for a model release: **not provided**
- Dataset/provenance approval: **not provided**
- Base-model and output-license approval: **not provided**
- Target-hardware quality/performance approval: **not provided**
- Security and final release approval: **not provided**

Do not change these fields based on CI success. A future release requires the
signed/restricted consent record, immutable provenance and artifact hashes,
license evidence, held-out evaluation, completed model-card template, and named
human approvals.

## Intended use and limitations

There is no approved model and therefore no approved synthesis use. Do not
represent fixture output as a voice, deploy it for end users, distribute model
artifacts, or infer that the voice owner has consented.

See `docs/model-card-template.md` for the evidence required by a future model
card and `docs/release/` for operational release gates.
